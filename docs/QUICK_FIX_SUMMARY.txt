⚡ QUICK FIX FOR SLOW LOADING - 277 CAMERAS
================================================================================

PROBLEM: Half of cameras stuck at loading, others load very slowly

SOLUTION: Implemented staggered loading and optimizations

CHANGES MADE:
================================================================================

1. STAGGERED LOADING
   - Cameras now load in batches of 20
   - 2 second delay between batches
   - 14 batches total for 277 cameras
   - Prevents overwhelming the system

2. REDUCED THREAD POOL
   - Changed from 277 threads to 100 threads
   - Prevents thread exhaustion
   - Better CPU utilization

3. FASTER TIMEOUTS
   - Initial load: 15s → 8s
   - Regular updates: 10s → 5s
   - Faster failure detection

4. OPTIMIZED RETRIES
   - Retries: 3 → 2
   - Retry delay: 0.3s → 0.2s
   - Error frame: 8 failures → 5 failures

5. FASTER ERROR BACKOFF
   - 0.3s → 0.5s → 1s → 2s (max)
   - Previously: 0.5s → 1s → 2s → 3s

6. REDUCED CACHE
   - 512MB → 256MB
   - Lower memory footprint

7. MINIMAL LOGGING
   - Less console spam
   - Only essential messages
