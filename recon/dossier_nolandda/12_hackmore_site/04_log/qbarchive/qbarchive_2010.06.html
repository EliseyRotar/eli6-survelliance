An update to the earlier things to install list. I have been meaning to post this for some time.

  • System Utilities
    • Launchy - Tab completion for starting windows programs.
    • Console - A better version of the windows cmd.exe shell
    • Unix-Utils - Allows Unix commands at the shell
    • Process Explorer - Replace the Windows Task Manager with something useful
    • WinDirStat - Keep disk usage in check
    • Eraser - Don't just delete files, kill them
    • Handle - Find out what process is holding the file handle and kill it
    • Taskbar Shuffle - Reorder running programs in the taskbar
    • Startup Control Panel - Allows you to disable stupid little programs that start at bootup without hunting them down in the registry
  • Manipulate standard files
    • IZArc - Extract or create compressed files (replaces WinZip and WinRar)
    • Notepad++ - Useful simple text editor
    • Acrobat PDF Reader - Read PDF files
    • Microsoft Office - If you have a copy; otherwise OpenOffice
    • Gimp - For heavy duty image manipulation
    • Picasa - For simple image manipulation and viewing
  • Network Apps
    • Putty - An ssh client to connect to a real computer
    • Pscp - An scp client so you can copy files to a real computer
    • Mozilla Firefox
      • NoScript
      • Adblock Plus
      • Session Manager
      • HashColouredTabs+
      • WorldIP
      • Flash Player - Flash must die, but can't live without it yet
      • User Agent Switcher - Pretend to be MSIE on sites that disallow Firefox (haven't needed this recently)
    • Pidgin - Universal instant messaging client
  • Rip, Burn, and Play Media
    • FreeRip - For ripping your albums to mp3
    • ImgBurn - For burning CDs and DVDs
    • WinAmp - The music player of choice
    • Media Player Classic - The video player of choice
      • QuickTime Alternative - Quicktime is evil
      • Media Player Codec Pack - Codecs for DivX et cetera
    • iTunes - The music player for updating the iPhone
  • Misc
    • Java Runtime and Dev Kit - Your browser wants Java
    • TightVNC - For remote control of your system
    • Xobni - If you are forced to use Outlook this plugin that allows efficent searching of your mail is absolutely essential
    • Password Safe - Store all of your passwords encrypted
    • Skype - Phone and chat
